MongoDB supports storing https://www.mongodb.com/docs/manual/geospatial-queries/#geospatial-data[Geospacial data] in both flat and spherical surface types.

To store data in a flat surface you use a "2d" index, whilst a "2dsphere" index used for spherical data. Grace Data MongoDB supports both and the following sections describe how to define and query Geospacial data.
