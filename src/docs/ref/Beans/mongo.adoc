=== Purpose

Provides access to the native https://mongodb.github.io/mongo-java-driver/5.0/apidocs/mongodb-driver-sync/com/mongodb/client/MongoClient.html[MongoClient] instance.

=== Examples

[source,groovy]
----
class FooController {

    MongoClient mongo

    def myAction() {
        MongoDatabase db = mongo.getDatabase("mongo")
        db.languages.insert([name: 'Groovy'])
    }
}
----

=== Description

See the API for the https://mongodb.github.io/mongo-java-driver/[Mongo Java Driver] for API usage info.
